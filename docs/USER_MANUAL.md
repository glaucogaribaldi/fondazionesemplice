# Fondazione Semplice User Manual

## Initial mode

The system starts in PAPER mode.

Each strategy receives:

310 USDC virtual capital.

Five independent portfolios:

- Lane 1
- Lane 2
- Lane 3
- Lane 4
- Lane 5

## Commands

START ALL

Starts all strategies from zero.

PAUSE

Stops new decisions while preserving state.

RESUME

Continues a paused strategy.

STOP

Ends the strategy lifecycle and generates a complete report.

## Strategy lifecycle

STOPPED -> RUNNING -> PAUSED -> RUNNING

or

RUNNING -> STOPPED

## Goal

Compare five strategies starting from equal capital and identify the strongest configuration before possible live activation.
